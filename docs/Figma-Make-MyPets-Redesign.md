# MyPets UI/UX Redesign Notes

## figma_make-main 实现的功能

`figma_make-main` 是一个偏高保真的 React/Vite 桌宠陪伴原型，核心信息架构包括：

- 首页工作台：展示当前宠物、宠物状态、AI 聊天框、快捷问题、任务列表和新增任务。
- 专注模块：提供番茄钟式计时、开始/暂停/重置等控制。
- 角色库：内置多个角色卡片，支持选择不同角色形象，并展示角色标签、描述和主题色。
- 数据统计：用卡片、趋势图等方式呈现专注、喝水、休息等陪伴数据。
- 设置模块：承载通知、声音、外观等偏好配置。
- UI 风格：奶油色背景、薰衣草紫主色、薄荷绿/珊瑚橙点缀，搭配 macOS 窗口感顶栏、圆润卡片和可爱角色大图。

## 对 MyPets 的取长补短

MyPets 的桌面宠物使用逻辑保持不变：桌宠继续常驻桌面、可移动、按状态播放动作、支持提醒、三击打开聊天，并通过 DeepSeek/API 模型完成问答。

这次融合主要补强“管理界面”和“角色运营”：

- 将设置页改造成 MyPets Studio：顶部增加宠物预览、mac 风格窗口点、分区导航，让设置页更像一个可爱的桌宠控制台。
- 首页增加产品模块概览：把 AI 聊天、Petdex 角色库、专注守护三个能力并列展示，方便用户理解产品价值。
- 重绘角色库：保留当前已安装角色选择，同时加入 Petdex 推荐入口，让用户可以按 chiikawa、usagi、hachiware、kuromi、cinnamoroll 等关键词去搜索并自行安装或导入。
- 保留并强化自定义 GIF：用户仍可为待机、左右移动、打招呼、跳跃、思考、失败、休息倒计时、待确认等状态分别上传 GIF。
- 融合相似功能：figma 原型里的任务/专注/数据看板能力映射到 MyPets 当前的提醒、休息、喝水、专注统计，不另起一套割裂流程。

## 角色库策略

Petdex 适合作为外部角色扩展入口，而不是直接把受版权保护的 IP 素材打包进仓库。MyPets 当前采用“搜索推荐 + 用户自行安装/导入”的方式：

- 内置项目仍保持可分发、可开源的基础角色和用户自定义 GIF。
- 推荐卡只打开 Petdex 搜索，不默认附带 chiikawa、kuromi、cinnamoroll 等受版权保护的素材文件。
- 后续可以补一个自动导入流程：用户输入 Petdex slug 后，MyPets 调用本地命令安装，再扫描 `petdex_pets` 并加入角色库。

## 后续产品路线

- 角色标签：为角色增加“治愈系、活力系、努力系、陪伴系”等标签和筛选。
- 角色人格：每个角色绑定不同 AI prompt，让三击聊天不只是换皮，而是语气和行为反馈都跟角色一致。
- 联网问答：在 DeepSeek 之外加 Web Search/RAG 工具层，用于天气、新闻、实时资料等问题。
- 离线评估：继续保留聊天评估脚本，对角色语气、拒答质量、联网问题兜底进行自动测试。
- 资产合规：对第三方角色资产提供来源展示、用户确认和本地导入记录。
