# MyPets Glossary

| Term | 中文 | Meaning |
| --- | --- | --- |
| Desktop companion | 桌面宠物 | 常驻在屏幕上的可交互宠物形象。 |
| Custom GIF pet | 自定义 GIF 形象 | 用户为不同宠物状态上传不同 GIF 动作。 |
| Pet state | 宠物状态 | 待机、移动、思考、开心、失败、复核等展示状态。 |
| Break reminder | 休息提醒 | 到达设定时间后提醒用户离开屏幕休息。 |
| Hydration reminder | 喝水提醒 | 定时提醒用户补水。 |
| Focus mode | 专注模式 | 一段受保护的工作时间，可结合分心检测提醒用户回到任务。 |
| Distraction detection | 分心检测 | 本地匹配当前应用或窗口关键词，判断是否触发专注提醒。 |
| AI chat bubble | AI 聊天气泡 | 三击桌宠后打开的聊天界面。 |
| Online context | 联网上下文 | 天气或即时问答等实时信息，被加入模型输入以降低幻觉。 |
| Fallback | 兜底 | API 失败、联网失败或信息不足时的解释和下一步建议。 |
| Eval set | 评估集 | 用来测试 AI 行为质量的一组固定问题和场景。 |
| Badcase | 坏例 | 低分或失败样本，用来定位问题属于检索、提示词、上下文、UI 还是模型能力。 |
| LLM-as-a-judge | 模型评审 | 用另一个模型或评审提示词批量给回答打分，通常需要人工抽样校准。 |
| Agent activity alerts | Agent 活动提醒 | 监听本地 Codex、Claude Code、OpenCode、DeepSeek TUI、Hermes 等工具活动并触发桌宠反馈。 |
